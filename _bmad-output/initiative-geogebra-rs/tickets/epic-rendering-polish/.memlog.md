- (decision) E4-AD-4-AMEND (amends parent AD-4): curves render as quad-ribbon triangle strips expanded in WGSL vertex shader with edge-AA in fragment shader. Line width range 2.5px min / 3.5px default / 6px max, width passed as per-vertex half-width in pixels, clamped in shader. Prevents wgpu 1px hairline divergence and per-story width drift.
- (decision) E4-DASH: derivative overlays (f-prime, f-double-prime) render as dashed ribbons via screen-space dash pattern in curve.wgsl fragment shader: 8px on / 6px off at 1x, computed from screen-space arclength varying, antialiased at dash edges. Solid for f(x). Prevents two stories inventing incompatible dash encodings (uniform flag vs separate pipeline).
- (decision) E4-STYLE-STRUCT: per-function style is struct FunctionStyle { color: [f32;4] linear-sRGB, width_px: f32, dashed: bool, visible: bool } owned by render crate (curve.rs), keyed by function id in wasm_bridge Session. Vertex buffer carries color+width+dash per vertex; visibility toggles skip buffer submission, never mutate stored style. Prevents Svelte holding parallel style truth.
- (decision) E4-PALETTE (Decision 2026-10-18 adopted): default 8-colour colourblind-safe palette assigned in order f, f-prime, f-double-prime, then user functions; user may override via set_function_style. Width defaults 3.5px, clamp [2.5, 6.0]. Prevents ad-hoc per-story colour picks that collide on 3-curve view.
- (decision) E4-AD-5-AMEND (amends parent AD-5, Decision 2026-10-18): parent says exactly four but lists five — fix count to five and add style surface: set_function_style(id, color_hex, width_px, dashed) and set_function_visibility(id, visible) (or single toggle_visibility equivalent). - (decision) E4-SHADER-CONTRACT: curve.wgsl owns vertex attributes (position_math: vec2f, normal_dir: vec2f, color: vec4f, width_px: f32, dash_flag: f32, arclength_px: f32) + uniforms (viewport rect, canvas_px, dpr). grid.wgsl owns grid uniforms (ticks, viewport, canvas_px) and draws lines only, never text. Shared with epic 3 under contract: epic 3 may add asymptote dashed-line draws via SAME curve.wgsl dashed path with reserved dash_flag=2, must not change attribute layout without E4 amendment. Prevents shader signature collision between epics.
- (decision) E4-VIEWPORT-GRID: Rust owns viewport state (wasm_bridge Session) + tick computation (grid.rs 1/2/5, max_ticks 10) + grid vertex emission; Svelte renders ONLY axis tick labels + tooltips as DOM/SVG overlay positioned from viewport_ticks via update_viewport/query_hover. Grid geometry updates synchronously on viewport change; labels may lag one frame. Prevents dual viewport truth and canvas-text atlas bloat.
- (decision) E4-GL-PARITY: all WGSL must compile under wgpu WebGL2 (GL) backend translation — no subgroup ops, no texture features beyond GLES3 subset, f32 only in shaders (f64 stays CPU-side). pipeline.rs requests Backends::PRIMARY | Backends::GL with silent WebGL2 retry. Curve/grid render paths identical on both backends; perf delta recorded not branched. Prevents WebGPU-only shader that silently breaks Safari.
- (decision) E4-PERF-HARNESS (Decision 2026-10-18): 60 FPS verified by continuous drag/zoom script on current Chrome (WebGPU), Firefox (WebGPU), Safari (WebGL2 fallback); 8ms verified by native cargo test (existing two_thousand_points_are_fast) + WASM bench for 2000-point vertex buffer incl. ribbon expansion. Frame budget split: sampler <8ms, ribbon expand + submit <8ms, total <16ms. Prevents per-story perf claims on incomparable harnesses.

Prevents double-ownership of singularity rendering.
